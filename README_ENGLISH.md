# RandomChoose
Welcome to use RandomChoose.

This program has developed by zhangxuan, started at Nov.1,2023, this is the full version.

## Usage

1. Download this program

Generally, you can directly download the latest version from the Releases on this page.

2. Setup
Open "Settings" and select the options you want according to your needs.

3. Start
Click "Start" and the program will automatically start the random selection.

## Building from Source
If you want to build this program from source, you need to install:
- Rust (Cargo);

Then, you can use the following command to build this program:
```bash
cargo build --release
```

Then, you can find this program in `target/release`.
